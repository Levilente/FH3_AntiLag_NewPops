# Anti-Lag (FH3)

Anti-lag for turbo cars in **Forza Horizon 3** (Xbox One build through Azimuth), a mod for the **FH3 Mod Platform**. Inspired by erikzensounds' FH2 Anti-Lag; written from scratch for FH3.

> **0.2.0 is a probe build.** The upgrade and the tuning rows exist; the anti-lag effect itself is not active yet. F8 records the car's physics objects to `fh3-mods\antilag-probe.bin` so the turbo's boost value and the pop trigger can be located.

- In the game's own turbo list (Engine > Turbo / Twin Turbo): **Race Turbo w/ Anti-Lag** after Street, Sport and Race.
- Tuning > Springs, rows for the car: pressure decay (ms), boost retention (%), cutoff RPM, pop interval (ms).
